How to Use

Database-free browser application.

Workflow

  1. Create a course profile (course code, program, semester, session and faculty).
  2. Complete OBE Curriculum and Course Design.
  3. Maintain Teaching & Learning resources.
  4. Enter Assessment & Attainment information.
  5. Attach supporting documents in Evidence Repository.
  6. Print / Save PDF from a course card.
  7. Export Backup frequently; import the JSON backup on another computer.

Storage and limitations

Course text is stored in browser Local Storage and evidence attachments in IndexedDB. No data is uploaded to a server. Clearing browser data may remove records; retain backups. There is no shared faculty login, central HOD view, approval workflow, ERP integration or automatic Word/PDF extraction in this no-database edition.
